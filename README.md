## 🚀 精选项目展示



### 1.  DDL Tracker 全栈记录管理系统
> - **技术栈**： ava (JDK 17)、Spring Boot、Vue 3 (Pinia/Composition API)、TypeScript、MySQL、Redis、Docker-Compose、Nginx、Spring Security、JWT、ECharts、Knife4j

> - **简介**:该项目是一个基于 RESTful 架构 的全栈一体化事项Deadline(截止日期) 追踪管理平台。针对生活多场景中“事项状态难同步、截止日期易遗漏、文件归类混乱”的痛点，构建了包含事项状态跟踪、截止日期提醒、简历附件关联及多维数据看板的全栈系统。项目采用前后端分离架构，引入 Redis 缓存架构与 Spring Security 权限框架，并利用 Docker-Compose 与 Nginx 实现了线上的容器化高可用集成部署。目前系统已全栈上云，提供公共测试账号，支持完整的真实登录、数据增删改及附件上传交互。
- [🔗 在线演示 ](http://47.110.124.30:8888/#/)
- [📂 源码仓库 ](https://github.com/ari-0210/job-tracker-fullstack)

### 2. Digital Closet - 电子衣柜
> - **技术栈**: Vue 3, Electron, Vite, Pinia, Tailwind CSS, PWA, Dexie.js, html2canvas
> - **简介**: 该项目是一款跨平台的交互式换装应用，允许用户为多款模特自由搭配，并支持用户上传、管理和自定义个人素材。项目基于同一套代码库，通过 Electron 打包为原生桌面应用，并利用 PWA 技术实现跨浏览器的类原生体验（如离线访问、桌面安装）。
